# License texts

The add-on is GPL-3.0-or-later. The full GPL text is in the root [LICENSE](../LICENSE)
and the installable package's [COPYING](../nvidia_audio2face/COPYING).
The explicit program grant is in [LICENSE.txt](../nvidia_audio2face/LICENSE.txt).

Bundled third-party notices are retained, unchanged, in
[nvidia_audio2face/LICENSES](../nvidia_audio2face/LICENSES):

- `MIT-nvidia-ace.txt` — NVIDIA protobuf stubs.
- `Apache-2.0-grpcio.txt` — grpcio.
- `BSD-3-protobuf.txt` — protobuf.
- `MIT-ict-facekit.txt` — USC ICT-FaceKit model.

`AGPL-3.0-historical.txt` preserves the former, conflicting root license text;
it is not the license applied to new GPL distributions. See
[LICENSING.md](../LICENSING.md) for the reconciliation and historical rights.
